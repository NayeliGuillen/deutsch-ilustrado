# Fotos de las palabras

Deja aquí una foto por palabra y la página la mostrará en lugar del dibujo.

## Cómo nombrar el archivo

La palabra **sin artículo**, en **minúsculas**, y con extensión **.jpg**:

| Palabra            | Archivo           |
|--------------------|-------------------|
| das Handtuch       | `handtuch.jpg`    |
| die Straße         | `strasse.jpg`     |
| die U-Bahn         | `u-bahn.jpg`      |
| der Käse           | `kaese.jpg`       |

Reglas: ä → ae, ö → oe, ü → ue, ß → ss; los espacios y símbolos se vuelven guiones.

## Consejos

- Fotos cuadradas o casi cuadradas, de unos 600 px de lado, quedan mejor.
- Una foto que subas desde la propia página (pegar, archivo, cámara) tiene prioridad sobre la de esta carpeta, pero solo se ve en ese navegador.
- Si cambias una foto por otra con el mismo nombre y la ves igual, sube el número de `VERSION` en `sw.js` para refrescar la copia sin conexión.
